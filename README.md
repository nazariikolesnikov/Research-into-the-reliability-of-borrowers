# Research into the reliability of borrowers

### General Results

During the study, the data were cleaned. Missing values in "total_income" and "days_employed" were hundled and negative employment duration values were replaced with absolute values as artifacts. Missing values were filled with medians. Text categories were brought to a single case and dublicated were removed. Dictationaries for "education_id" and "family_status_id", income categories and credit purpose categories were created.

Based on the results of the summary tables, I drew the following conclutions:

1.) Number of children and marital status show differences in proportion of overdue payments between groups;
2.) The income level is also assosiated with the proportion of overdie payments, specifically, the risk differs across different income categories;
3.) The purpose of the loan affects the observed propotion of overdie payments.
The result obtained should be interpreted as statistical patterns, not as strict case-and-effect relationships. For credit scoring, these factors may be useful, but they need to be verified using additionl data and models that control for other factors.
